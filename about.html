About

Welcome to the official webpage of the Rising Lounge Minecraft server network. The network's main focus is its creative plot server, but there are other activities in the lobby server.

There is an in-game shop where players can buy cosmetics and weapons to fight others in the PvP lounge in the lobby server.

All items are purchased with in-game currency and there will never be anything for sale using real currency.

The server is owned by and was created by rising308. You are free to take any assets (server resource pack, plugin source code, etc.) and do whatever you like with them.
